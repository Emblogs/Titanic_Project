# Titanic Survival Prediction 

Predicting passenger survival on the Titanic using Machine Learning.

## Tools Used
- Python, Pandas, Scikit-learn, XGBoost

## Approach
- Exploratory Data Analysis with Pandas
- Data preprocessing with Sklearn Pipelines
- Handled missing values with SimpleImputer
- Encoded categorical features with OneHotEncoder
- Model: XGBoost Classifier
- Evaluated with Cross Validation (avg ~83% accuracy)

## Results
Cross Validation Scores: [0.799, 0.809, 0.871, 0.809, 0.848]

## Dataset
[Kaggle Titanic Competition](https://www.kaggle.com/competitions/titanic)
